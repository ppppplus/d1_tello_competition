# Rounded Tello-style display geometry

These are original procedural display meshes generated by `generate.py` (Apache-2.0), in metres, with smooth vertex normals. They replace the flat box shell and segmented guard visuals only. The competition model retains its existing collision geometry, mass, inertia, joints, camera sensors and controller.

Visual references consulted on 2026-10-31:

- Ryze Tello official product page: https://www.ryzerobotics.com/tello
- Official aircraft diagram, Tello User Manual v1.2, page 4: https://dl-cdn.ryzerobotics.com/downloads/Tello/20180404/Tello_User_Manual_V1.2_EN.pdf
- Public simulation project: https://github.com/albanomarcus/tello_pkg

No meshes or textures from those references are redistributed. This is a simplified appearance approximation, not official CAD or a dimensionally exact replica. Arms, motors, feet and propellers retain the BSD-3-Clause tello_sim geometry documented in THIRD_PARTY.md.

Regenerate with Python 3 and NumPy: `python3 generate.py`. Generated DAE assets are shipped; students do not need to run the generator.
