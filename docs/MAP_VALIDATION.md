# 随机规则与地图验收（v2.0.0，2026-10-21）

## 场地

沿用最新布局：灰色底板 10.36 × 9.26 m，上方与右侧外墙贴齐二层，黑色地板边框、黄色门框，六扇统一蓝框窗。楼梯低端朝俯视图下侧，8 级、级高 0.1 m。二层左侧集合区上黄下蓝，D1 `(1,8)`、Tello `(1,6.85)`。

六个候选点统一侧面结构、靶板、投放垫和标牌支架；标牌只有朝上平面的颜色不同，侧面与背面中性灰。任务色使用独立可见性位，无人机俯视及教师总览可见，机器狗相机不可见，即使在二层向下看也不会看到任务色。位置编号按楼层从左到右约定，不在顶部印不同数字。运行时随机红/绿/蓝各一点，其余灰色；颜色分别对应打靶、投放一件、投放两件、不处理。两层均有任务。

## 自动检查与边界

`python3 -m unittest discover -s tests -v`：200 个种子的可复现性、两层覆盖、红/绿/蓝任务数、总物资数量、六个窗位、手动窗位覆盖，以及随机颜色变化仅发生于顶部可视面。

完整物理回归覆盖两个种子，并非穷举所有随机组合。默认演示使用模拟俯视报告；学生模式默认使用外部识别报告。无人机穿窗/巡航仍为参考航点控制，随机窗不等同于已实现视觉自主导航。机载公开状态不提前提供任务颜色；本地裁判文件仍有真值，正式比赛需另外隔离。
