## 实测

v1.6.1 只调整地面可视范围与边线；已逐项确认碰撞体、物理参数和路线未变，并重新完成 Gazebo 渲染。以下完整比赛结果来自 v1.6.0，未重复运行。

默认 2 号窗完整比赛 **3/3 通过**，`strict_pass: true`，用时 **293.561 秒仿真时间**。
完成穿窗、首报、进门、打靶、从下侧梯脚爬上八级台阶、两次投放，以及左上角两机集合。

- 两次投放误差 0.1138 m、0.1576 m，均小于 0.2 m。
- D1 集合误差 0.0896 m；Tello 水平误差 0.0000 m。
- Tello 在 281.541 秒实际接触 `upper_platform` 停稳并停止旋翼；降落后与 D1 最小水平距离 1.567 m。
- 无人机与机器狗均只从规定入口入楼一次；无人机留在二楼集合，不需要穿窗出楼。
- 未修改控制器和冻结权重，没有初始化后的机体位姿覆盖或机器狗外加抬升力。

验收范围为一个默认窗位的完整物理仿真和地图几何一致性检查。使用 ROS 2 Humble / Gazebo Fortress 6.16；教师演示为预设航点与已知地图高度，不代表图像自主识别。

## 复现

```bash
ros2 launch d1_tello_competition competition.launch.py gui:=false rate:=0 exit_on_finish:=true
```

`result.json` 应包含 `strict_pass: true`、`completed_count: 3`、`uav_landed: true`、`entry_validation.passed: true` 和 `rally_validation.dog_at_rally: true`。
