## 实测结果

使用 ROS 2 Humble / Gazebo Fortress 6.16、冻结 D1 步态，50 Hz 策略推理 / 1000 Hz 关节 PD；载荷动力学与模型尺寸保持原样。

默认 2 号着火窗的最终布局完整比赛 **3/3 通过**，`strict_pass: true`，耗时 **319.801 秒仿真时间**。
实测完成无人机穿窗、首报、D1 进门、平地与转向、8 级内嵌楼梯、打靶、两次投放、二楼集合和无人机平台接触降落。

- D1 集合位置误差：0.0773 m；Tello 集合位置水平误差：0.0000 m。
- 无人机于 306.996 秒接触 `upper_platform` 并停稳，停止旋翼；降落后与 D1 的最小水平距离为 1.566 m。
- 两次投放误差为 0.1256 m 与 0.1203 m，均小于 0.2 m；红靶有实体接触并倒下。
- 无人机与 D1 均只入楼一次；全程无人机没有出楼，结束位置在二层。`entry_validation.window_exit_required: false`，`rally_validation.dog_at_rally: true`。
- 没有通过初始化后的机体位姿覆盖或外加抬升力完成路线。

本次完成一个默认窗位的完整物理仿真回归，未重复此前其余五个窗位的入楼验收。图像由实际 Gazebo 相机渲染；当前地图预览见 README，历史布局可查看提交 400776d。
教师演示仍使用预设航点与已知地图高度，不代表已经实现图像自主识别。
